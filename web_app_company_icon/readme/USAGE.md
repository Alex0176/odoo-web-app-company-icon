Nothing to configure: install the module and reload Odoo. The name of the web app stays in
*Settings ‣ General Settings ‣ Web App Name*.

The image is centered on a white square with a small margin (192, 512, 180 and 32 pixels), so wide logos work, too.
Square images with a good resolution look best. Installed web apps update themselves like they do after a changed app name: the manifest changes with the image
(and with the company color), and browsers check it when the app is started (Chrome about once a day, Android
re-installs the app silently, iOS keeps the icon of the day of installation).

The icons are available at `/web/company_icon/<192|512|180|32>.png`.
