Uses your own icon for the installable **web app** of Odoo (the "Install app" feature of the browser: home screen,
taskbar, app switcher) and for the browser tab of the backend, instead of the Odoo icon.

The image is taken from

1. the **favicon of the website** that answers the request (Website ‣ Configuration ‣ Settings ‣ Favicon), or else
2. the **company logo**.

The **color of the app** (title bar, start screen, browser theme color) is the primary color of the company
(Settings > Companies > Colors) instead of the Odoo purple.

As long as a company still has the default Odoo logo and no website favicon is set, the icons stay; a company without a primary color keeps the Odoo purple.
